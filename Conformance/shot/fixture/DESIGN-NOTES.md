# What separates a designer-grade store slide from a rendered one

Read off five reference sets (PDF converter, gym tracker, Santa AI, calorie counter, language
app). Every one of them does all of these; the first version of this pipeline did almost none.

| # | Device | Why it reads as professional |
|---|---|---|
| 1 | **The slide is a CARD**, not full bleed: a rounded rect inset on a neutral ground, with gutters between slides | The set reads as a designed strip in the gallery rather than five unrelated posters. Every reference does this. |
| 2 | **Two-tone headline** - one or two words in an accent colour or a highlight box | The single most consistent device across all five. It carries the emphasis a flat white headline cannot, and it is what makes the copy scannable at thumbnail size. |
| 3 | **Heavy, tight display type** - 800/900 weight, negative tracking, often 2 lines | The references are noticeably heavier than a UI type ramp. Marketing type is not product type. |
| 4 | **A laurel award lockup** with stars and a short claim | Three of five. It is the "social proof" beat, and it is drawn art, not a store badge. |
| 5 | **Callouts with ARROWS**, not just rings | The references point at UI with curved arrows and a labelled pill. A ring says "look here"; an arrow says "look here, from over there", which is what lets the label sit on clean ground. |
| 6 | **Floating objects that overlap the device** - cutouts, 3D props, paper | Depth. The device stops being a rectangle pasted on a gradient. |
| 7 | **The device is cropped by the card**, not centred inside it | Three of five crop the phone at the card's bottom edge. It implies continuation and gives the headline room. |
| 8 | **Review cards** - a real quote, stars, an attribution | The strongest trust device available that is not a store award. |
| 9 | **An accent-tinted panel** behind supporting copy | Separates the promise from the proof without a second background. |
| 10 | **One theme across the strip** - same ground, same accent, same type | What makes eight slides look like one product. |

## The rule this produces

A slide is a THEME plus a HEADLINE plus a DEVICE plus DECORATIONS. All four are data, so the
agent composing a set is choosing values, never authoring layout - and a set is consistent
because the theme is set once for the strip rather than per slide.
